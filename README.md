# Real Estate Management System - Backend

## Overview

RESTful API powering a real estate management platform.

## Architecture

Route
↓
Controller
↓
Service
↓
MongoDB

## Features

- JWT Authentication
- User Management
- Property Management
- Category Management
- Statistics

## Technologies

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT
- BREVO
- SUFY
